# Prime Shield Chemical — Website

Static e-commerce site (HTML/CSS/JS). Orders WhatsApp par jate hain: 03483313337.

## GitHub Pages par live karna
1. github.com par naya repository banayein (e.g. `prime-shield`), Public rakhein.
2. "Add file → Upload files" mein is folder ki saari files (index.html, css, js, images, .nojekyll) drag karein, **Commit** karein.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. 1-2 minute baad link milega: `https://<username>.github.io/prime-shield/`

## Edit karna
- Price, naam, size, number: `js/products.js`
- Real product photo: `images/products/<id>.jpg` (cockroach, termite, bedbug, ant-lizard, mosquito)
- Colors: `css/style.css` ke upar `:root` mein
